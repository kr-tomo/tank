# TANK

배틀 시티(1985)를 현대화한 웹 게임(PWA). 기획은 `../proposal/`, 구현 계획은 `../docs/plan.md`, 컨셉 아트는 `../concept/index.html`.

## 실행

이 `src/` 폴더가 앱 루트이고 **GitHub Pages 에 그대로 올라간다**. 빌드 없이 정적 파일로 동작하며, 서비스 워커와 ES 모듈 때문에 HTTP 로 서빙해야 한다.

```sh
cd src
npm run serve          # http://localhost:8080 (같은 Wi-Fi 의 태블릿용 주소도 출력, no-cache)
npm run serve:https    # https://<IP>:8443 자체 서명 인증서 (태블릿에서 컨트롤러·오프라인 시험)
npm test               # 순수 로직 테스트 (node --test)
npm run build:sprites  # tools/art 로 themes/*/ 스프라이트·theme.json·아이콘·concept/index.html 재생성
npm run build:sfx      # 효과음 합성 → sfx/*.wav
npm run dist           # ../dest/tank-v<N>.zip (배포본, tools/tests 제외)
```

버전은 `js/version.js` 의 `APP_VERSION` 하나다. 올리면 `sw.js` 의 `CACHE` 도 같이 올린다(테스트가 두 값을 비교한다). 타이틀 화면에 `v<N>` 으로 표시된다.

## 구조

- 규칙(`grid`, `units`, `projectile`, `world`, `enemy`, `stages`, `editor`)은 Phaser 와 무관한 순수 JS. `tests/` 가 검증한다.
- `stage.js` 가 Phaser 4(`vendor/`) 로 그리고 파티클·카메라·사운드를 더한다. `editorscene.js` 는 편집기 화면.
- `layout.js`/`input.js`/`menu.js` 는 versus 에서 이식: 가상 패드 배치(사이드/하단, 75% 규칙), 게임패드 배정, 메뉴 탐색.
- 테마는 `themes/<id>/theme.json` + `sheets/*.svg`. 로직은 지형 id·유닛 역할·아이템 id 만 알고, 테마가 그림·이름·탄 규칙(`rules`)·적 특성(`traits`)·효과음을 붙인다. 새 테마는 폴더 하나와 같은 구조의 JSON 만 추가하면 된다. 유닛 그림은 위를 보는 2프레임이고 렌더러가 회전한다.

## 테마별 규칙

| 테마 | 탄 | 특성 |
|---|---|---|
| 클래식 | 직선, 0.35초 간격 연사(비행 중인 탄 수 제한 없음), 탄끼리 상쇄 | 얼음 미끄럼 |
| 고대 투석기전 | 포물선(표적 착지: 첫 적 → 첫 벽 → 사거리 끝), 착지 2×2 파괴, 비행 중 무충돌 | 공성탑이 벽돌을 뭉갬, 진흙 감속 |
| 우주 함대전 | 레이저: 머리가 4타일을 약 0.17초에 날아가며(768px/s) 발사 지점부터 머리까지의 궤적이 직선 빔으로 남고, 궤적에 닿은 유닛도 피격된다. 다른 레이저의 궤적과 겹치면 두 레이저 모두 겹친 지점 이후가 즉시 무효가 된다. 폭 10px, 요새 밖 강철에서 최대 2회 반사(맞은 블록 중심에서 치우친 쪽으로, 정중앙이면 좌우 번갈아), 반사마다 3타일 사거리, 과열 0.5초 | 요격기 회피, 무중력 관성 |
| 할로윈 유령전 | 유령 전차가 벽 위에서 실체화되면 가장 가까운 빈 자리(최대 8타일)로 옮겨지고, 빈 자리가 없으면 제거되어 다음 적이 나온다. 도깨비불: 좌우 사인파(진폭 5px·주기 1타일)로 나아가며 4타일은 직진, 그 뒤 진행 방향 ±45° 안 가장 가까운 적에게 유도(최대 150°/s, 시야를 벗어나면 락 해제, 지형은 무시하되 경로의 지형에는 피격), 8타일 뒤 소멸 | 유령 2초 주기 투명(벽돌 통과·무적·발사 불가), 요새 구역에서 실체화 |

본진 둘레 3×3 타일(요새 구역)에서는 테마 특수 규칙이 꺼진다.

## 조작

| 행동 | 게임패드 | 가상 패드 | 키보드 P1 / P2 |
|---|---|---|---|
| 이동 | D-패드, 왼쪽 스틱 | 십자키 | WASD / 방향키 |
| 발사 | A, B (누르고 있으면 연사) | 발사 | F / K |
| 일시정지 | Start | ❚❚ | Esc |
| 편집기 | D-패드 커서, A 배치, B 지우기, Y 지형, X 붓 | 터치로 칠하기 + 아래 도구 막대 | 방향키, Space, Backspace, Tab, Q |

가상 패드 규격은 versus v14 와 같다: 버튼은 화면 짧은 변의 19.5%(66~126px), 십자키는 버튼 1.9개 폭. 가로 화면에서는 뷰가 세로를 꽉 채우고 패드가 뷰 가장자리를 절반까지 덮는 반투명 오버레이로 놓이며, 사이드/하단 배치는 뷰가 더 넓어지는 쪽을 고른다. 십자키는 손가락이 처음 닿은 뒤 떨어질 때까지 패드 중심 기준 각도로만 방향을 읽는다(밖으로 벗어나도 유지). 메뉴 화면도 패드 방향키로 포커스를 옮기고 Ⓐ 선택, Ⓑ 뒤로 간다.

게임패드가 연결되면 그 플레이어의 가상 패드는 사라지고 메인 뷰가 그 자리를 차지한다. Safari 는 패드 버튼을 한 번 눌러야 인식하고, 패드·서비스 워커는 HTTPS 또는 localhost 에서만 열린다.

## 설정

설정 화면에서 목숨(3~10, 그 다음 ∞)과 피격 모드를 고른다. 파괴 모드는 피격 시 전차가 터지고 다음 전차가 나오며, 데미지 모드는 피격 이펙트와 함께 목숨만 1 줄고 같은 전차로 이어서 플레이한다(1초 무적). ∞ 목숨이면 데미지 모드에서 차감이 없다. 앱 아이콘은 `tools/art/extract.py` 가 할로윈 아트웍스의 호박 전차로 만든다.

## 방어 로직

- 스테이지가 12초 안에 준비되지 않거나, 일시정지가 아닌데 게임 시계가 4초 동안 멈추면 장면을 다시 만든다(최대 2회, 그 뒤엔 오류 상자). 이미지 로딩은 8초 타임아웃 후 캐시를 우회해 한 번 재시도한다.
- 등장할 적이 더 없는데 남은 적이 모두 8초 이상 제자리면(또는 60초가 지나면) 남은 적을 제거해 스테이지를 끝낸다.
- 아군 탄에 맞으면 1초 경직. 경직이 풀리기 전에 세 번째로 맞으면 실제 피격으로 처리된다(파괴 모드: 파괴, 데미지 모드: 목숨 -1).

## 맵 편집

타이틀 → 맵 편집. 협동(13×13)·대전(19×13) 규격을 고르고 반타일 단위로 칠한다. 도구 막대의 1P 아이콘은 시작 위치 도구로, 칸을 누를 때마다 1P·2P 시작 위치가 번갈아 옮겨진다. 적 아이콘은 적 등장 위치 도구로, 누를 때마다 세 곳 중 가장 오래전에 정한 곳이 옮겨온다. 위치를 놓으면 그 타일의 지형은 지워지고, 본진과 현재 시작·등장 타일은 칠할 수 없다. 위치는 맵과 함께 저장된다. "시험 플레이" 중 ⌂ 버튼의 확인 창에서 "편집으로 돌아가기"로 편집기로 복귀한다(스테이지가 끝나도 편집기로 돌아온다). `localStorage["tank.maps.v1"]` 에 최대 50장 저장되며, 내보내기/가져오기는 JSON 텍스트를 복사·붙여넣기한다. "시험 플레이" 는 저장 후 그 맵으로 바로 시작한다.

## 아트

`../art/` 의 규격서(PDF)와 테마별 참고 시트가 원본이다. 시점이 무관한 요소(지형 타일·아이템·본진·이펙트·탄)와 탑뷰로 그려진 유닛(클래식 전차, 우주 함선)은 `tools/art/extract.py` 가 참고 시트에서 직접 잘라 4배 해상도 PNG 시트(`sheets/*.png`)로 만든다. 3/4 시점이라 그대로 쓸 수 없는 유닛은 탑뷰로 다시 만든다: 할로윈 호박 전차는 클래식 탑뷰 차체를 테마색으로 물들이고 아트웍스의 호박 머리를 포탑으로 얹어 합성하고, 고대 투석기는 `tools/art/ancient.js` 가 참나무·철·밧줄 재질로 벡터로 그린다. `npm run build:sprites` 는 PNG 가 있는 시트는 PNG 를, 없는 시트는 벡터 SVG 를 `theme.json` 에 적는다(`cells` 는 시트별 논리 셀 크기, `scales` 는 PNG 의 배율). 참고 시트를 바꾸면 `python3 tools/art/extract.py` 뒤에 `npm run build:sprites` 를 다시 실행한다. 테마 카드는 타일·본진·P1 을 조합한 디오라마와 탄 규칙 배지를 보여 주고, 선택한 테마의 팔레트가 CSS 변수(`--bg --hud --accent --p1 --p2`)로 전체 UI 에 들어간다. 발사 버튼 가운데에는 현재 테마의 탄 스프라이트가 투영된다.

## 배포

`npm run dist` 가 `../dest/tank-v<N>.zip` 을 만든다. zip 루트에 `index.html` 이 있으므로 압축을 풀어 GitHub Pages 브랜치/폴더에 그대로 넣으면 된다(`tools/`, `tests/`, `package.json` 제외).
